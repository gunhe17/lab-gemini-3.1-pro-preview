# step1 — 이미지 골격(구조) 인식 확인

작성일: 2026-06-02

## 한 줄 목표

좌표(계량)를 분리하고 **표의 골격(열 수·헤더 단·병합·중첩·읽기순서)만** 단독 측정해,
이 모델이 골격 단계에서 실제로 뛰어난지 / 어느 난이도부터 무너지는지 찾는다.

## 배경

[docs/가설1.md](../docs/가설1.md): box_2d 같은 **계량 출력은 양자화 토큰 추측이라 약하다.**
그렇다면 모델의 강점은 좌표가 아니라 **관계·구조(골격)** 인식일 것 —
이 단계가 그 가설을 정량 검증한다. (가설1은 "관계 신호도 부실할 수 있다"고 경고했고,
골격마저 흔들리면 텍스트 앵커 의존도를 더 높여야 한다.)

## 폴더 구조

```
step1: 이미지 골격 인식 확인/
├── README.md          ← 이 파일 (인덱스)

├── manifest.md        입력 이미지 ↔ 난이도(L1~L4) 매핑

```
