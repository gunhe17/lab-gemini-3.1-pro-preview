# 입력 5장에서 추출한 복잡 구조 특성 카탈로그

목적: 실제 input 이미지(p-005·007·011·017·038)의 **구조적 난점**을 분해해,
같은 난점을 갖는 **합성 HTML(=완벽한 정답)** 을 작성하기 위한 명세.

> 합성 전략: HTML을 우리가 직접 작성 → 그 HTML이 곧 정답(GT).
> HTML → PNG = 모델 입력, HTML → JSON = 정답 골격. 손 라벨링의 불확실성 제거.

## 3. 합성 데이터셋 사다리 (각 표 1개로 격리)

특성을 **한 칸씩 누적**해 "어느 특성부터 구조 인식이 무너지는지" 경계를 찾도록 설계.

| id | Lv | 누적 특성 | 노리는 것 | 모델 대응 |
|----|----|-----------|-----------|-----------|
| `s0-grid` | L0 | (없음) 단순 N×M 격자, 단일 헤더 | 기준선(ceiling). 여기서 틀리면 다 무의미 | p-038의 단순 부분 |
| `s1-rowspan` | L1 | +C2 | 세로 행머리글 병합만 단독 | p-005 |
| `s2-multihead` | L2 | +C3 | 다단 열 헤더(colspan parent)만 단독 | p-038 검사도구 |
| `s3-form-bands` | L2 | +C1,C6,C7 | 전폭 밴드 + 빈칸·체크박스 + 본문 병합 (폼) | p-038 전체 |
| `s4-nested-asym` | L4 | +C4,C5 | 중첩표 + **비대칭 형제** (재귀 + 깊이) | p-007 |
| `s5-noruling` | L3 | s2와 동일 구조, 괘선만 제거(+C8) | 괘선 의존도 격리(s2와 직접 비교) | p-017 |
| `s6-p011clone` | L3 | C2,C4 (+조밀 불릿) | **입력 p-011 구조 복제** (5열, 기존/변경 칸 내 부가서비스 중첩표) | p-011 |

- **s5는 s2의 무괘선 쌍둥이**: 내용·구조 동일, 선만 제거 → 점수 차이 = 순수 괘선 의존도.
  ("순수 구조 인식"을 향한 첫 절제 실험.)
- 추후 확장: C9(세로쓰기) `s6-vtext`, 내용 더미화(글자→■) ablation 변주는 같은 추출기로 재생성.

## 4. 산출물 규약

```
synthetic/
├── characteristics.md       ← 이 문서
├── html/<id>.html           ★ 사람이 검수할 유일한 정답 소스 (우리가 작성)
├── png/<id>.png             HTML→렌더 (모델 입력)
├── gt/<id>.skeleton.html    ★ 정답 골격 (빈 셀 HTML, TEDS-Struct 채점 기준)
├── gt/<id>.gt.json          보조: 사람용 구조 요약·스칼라 지표 (정답 아님)
├── render.py                HTML→PNG (Chrome headless + PIL 트림)
├── extract_gt.py            HTML→JSON 트리 (보조 요약)
├── skeletonize.py           HTML→빈 셀 골격 HTML (정답·예측 공통 정규화기)
└── teds.py                  TEDS-Struct 채점기 (Zhang-Shasha)
```

## 5. 정답·채점 설계 (확정)

- **정답은 HTML 하나**다. JSON 정답은 만들지 않는다 — 검수 대상은 `html/*.html`(=PNG)뿐.
- U1 모델 출력 = **빈 셀 골격 HTML**. 정답도 `skeletonize.py`로 같은 형식으로 깎아둔다.
- 채점: 예측·정답 둘 다 `skeletonize` → 동일 정규화 → **TEDS-Struct**.

골격 정규화 규칙(`skeletonize.py`):
- 남김: `table / tr / td` + `colspan`·`rowspan` + 중첩표
- 버림: 텍스트, 스타일, class, 비표 요소(ul·div…)
- **`th`/`td` 무관 → 전부 `td`로 통일** (순수 격자 기하만 채점)

검증 완료: 자기유사 1.000, **s2≡s5(무괘선 쌍둥이) 1.000**(점수차=순수 괘선효과 보장), 섭동 민감.
