# 테스트 세트 매니페스트

가이드 §3 난이도 사다리에 각 입력 이미지를 배정한 표.
파일럿 단계라 레벨당 1장(가이드 권장은 3~5장). 출처는 `data/pdftopng/`.

| page | level | 특성 | 비고 |
|------|-------|------|------|
| p-038 | **L1** | 깔끔한 괘선 폼(소견서). 섹션 밴드 + 단순 병합 + 체크박스 행 | 가장 정형적. 검사도구 블록에 미니 2단 헤더 존재 |
| p-005 | **L2** | 사업별 주요내용. 행 머리글(구분/사업명)이 여러 행 병합, 단일 헤더, 괘선 | 행 병합 정확도 1차 시험대 |
| p-011 | **L3** | 기존/변경 비교. 셀 안 중첩표(inner table) + 행 병합 | 중첩 식별 시험 |
| p-017 | **L3** | 기존/변경 비교. 세로 병합 머리글 + 중첩 + 조밀 | p-011과 동급, 세로 라벨 변형 |
| p-007 | **L4** | 변경내용 비교표. 중첩 inner table + 병합 섹션 라벨 + 조밀 | 현실적 난표, 무너지는 지점 후보 |

## 갭

- **L0**(병합 없는 단순 격자)와 **순수 무괘선** 케이스는 현재 세트에 없음.
  경향이 보이면 해당 레벨 이미지를 추가 수집해 사다리를 메운다.

## 명명 규약

- 입력: `inputs/p-NNN.png` (출처 페이지 번호 유지, 레벨은 본 매니페스트로만 매핑)
- 정답: `groundtruth/p-NNN.json` (사람 라벨)
- 출력: `outputs/p-NNN.<condition>.json`
  - `A` = 관계 앵커(주 조건), `B` = 좌표·서수(대조군)
  - 일관성 샘플: `outputs/p-NNN.A.k<3>.json` (K회 반복)
