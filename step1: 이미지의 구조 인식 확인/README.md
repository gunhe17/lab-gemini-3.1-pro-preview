# step1 — 이미지 골격(구조) 인식 확인

작성일: 2026-06-02

## 한 줄 목표

좌표(계량)를 분리하고 **표의 골격(열 수·헤더 단·병합·중첩·읽기순서)만** 단독 측정해,
이 모델이 골격 단계에서 실제로 뛰어난지 / 어느 난이도부터 무너지는지 찾는다.

## 배경

[docs/가설1.md](../docs/가설1.md): box_2d 같은 **계량 출력은 양자화 토큰 추측이라 약하다.**
그렇다면 모델의 강점은 좌표가 아니라 **관계·구조(골격)** 인식일 것 —
이 단계가 그 가설을 정량 검증한다. (가설1은 "관계 신호도 부실할 수 있다"고 경고했고,
골격마저 흔들리면 텍스트 앵커 의존도를 더 높여야 한다.)

## 접근 (수정됨)

이 문서군은 전부 **표 안에 표/텍스트가 든 재귀 구조**라, 고정 골격 스키마(단층 격자)와
사람 정답(GT)을 강제하는 게 비효율적이었다. 그래서 방향을 바꿈:

> **정답 라벨을 강제하지 않고, 모델이 중첩을 스스로 '열린 JSON 트리'로 그리게 한다.**
> 평가 = (1) 이미지 ↔ 트리 **위상 일치를 눈으로 검수**, (2) 호출 간 **일관성**(정답 불필요).

가설1 정합: 위상(트리)은 모델 강점, 계수(행·열 수)는 약점 — 열린 구조면 위상이 살아남는지 직접 본다.

## 폴더 구조

```

├── manifest.md         입력 이미지 ↔ 난이도(L1~L4) 매핑
├── extract_skeleton.py ★ 열린 재귀 JSON 트리 추출기 (좌표 금지)
├── build_report.py     이미지 ↔ 트리 검수 리포트 빌더
├── inputs/             p-NNN.png (표 1개씩 격리)
├── outputs/            p-NNN.skeleton.json (모델 출력: parsed 트리 + raw + usage)
├── groundtruth/        p-NNN.json (초안 — 참고용, GT 강제 폐기)
└── report.html         ★ 검수 산출물
```
